Bozza per discutere come pezzi grafici indipendenti si agganciano a un corpo comune. È uno schema 2D: i cerchi rossi sono porte anatomiche, i cerchi ambra sono ancoraggi per accessori.

Ogni porta ha posizione e orientamento locali. In 2D una porta allinea posizione e angolo; due porte possono vincolare anche la scala. La forma esterna resta libera, ma il bordo vicino all’attacco va disegnato per sovrapporsi bene.

Esempio di manifesto modulo

L’asset contiene il disegno. Il manifesto dice cosa offre, cosa richiede e in quale ordine si disegna. Il renderer non deve conoscere le regole di sblocco.

{
  "id": "ali.fantasia.base",
  "version": 1,
  "asset": "ali-fantasia.svg",
  "slot": "schiena",
  "requires": [
    { "port": "attacco_sx", "connectsTo": "torso.spalla_sx" },
    { "port": "attacco_dx", "connectsTo": "torso.spalla_dx" }
  ],
  "ports": {
    "attacco_sx": { "x": 28, "y": 46, "angle": 155 },
    "attacco_dx": { "x": 92, "y": 46, "angle": 25 }
  },
  "drawOrder": 20,
  "tags": ["fantasy", "ali"]
}

Perimetro della bozza

La proposta iniziale è uno scheletro 2D canonico con slot e porte nominati, SVG come asset e un compositore che applica trasformazioni e ordine dei livelli. Non è un sistema di rig completo: pose e deformazioni si aggiungono solo se servono animazioni articolate.

La medaglia è un accessorio ancorato al petto; l’eventuale regola che la sblocca appartiene al motore di progressione e non al manifesto grafico.
