# Animazioni create o riadattate

Questa cartella conserva e versiona le animazioni create o riadattate nel laboratorio. Per ogni nuovo risultato annotare provenienza, clip sorgente, rig di destinazione, licenza, stato e verifiche quando disponibili. Non indicare come approvata un'animazione solo perché il file esiste.

Le animazioni confermate che hanno già una destinazione nell'app non richiedono una seconda copia qui. Per il pacchetto avatar attuale consultare `pacchetto/strumenti/LEGGIMI.md` e documentare le fonti in `pacchetto/clip/FONTI.md`.

## File presenti

- `Delusione_Defeat_Medium.glb`: prova per KayKit medium legata agli esperimenti su Delusione/Defeat. Gli script `tools/build_delusione_ik.py` e `tools/retarget_defeat_to_kaykit.py` indicano entrambi questo percorso di output; non è stato accertato quale abbia prodotto l'ultima versione del file. Risultato sperimentale non approvato; provenienza esatta e resa da verificare prima dell'uso.
